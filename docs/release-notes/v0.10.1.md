# SiftWire v0.10.1

## Changed

- Fetch upcoming fixtures as well as results for ESPN soccer team schedules without an explicit `fixture` query, preserving the configured reporting windows. Explicit fixture queries retain their scope; a failed required read fails the source check rather than silently reporting incomplete coverage.
- Link supported ESPN team schedules to public game pages instead of odds pages or raw APIs, and label upcoming MMA times as event starts rather than headliner walkout times.
- Keep continuing failed checks and empty optional-news feeds visible in source-coverage notices, alongside health transitions. Empty feeds do not establish an absence of news.
- Adopt the shared renderer's responsive header and fix sports rows without logos. Remove a duplicate publisher suffix from HTML headlines when the same publisher already appears in the row label.
- Supply publisher-provided feed summaries in collection results for editorial research. These summaries are untrusted metadata, not verified article contents or generated delivery prose.
- Include dependency and TLS validation fixes already merged since v0.10.0.

## Upgrade

Install the v0.10.1 runner and same-tag skill. Runner protocol v5, configuration, the database schema, Mailgate transport, and immutable prepared-delivery replay remain unchanged. Existing prepared bodies are never rerendered during the upgrade. No separate renderer installation is required for SiftWire; the release binary embeds its pinned renderer.

## Verification

Run `mise exec -- ./scripts/ci.sh` and `mise exec -- ./scripts/validate-release-docs.sh v0.10.1`. These gates cover the pinned dependency integration, formatting, strict lint, runner and evaluator tests, TypeScript checks, shell checks, skill validation, and release installation. They do not establish live delivery, complete provider coverage, or factual verification of every selected story.
