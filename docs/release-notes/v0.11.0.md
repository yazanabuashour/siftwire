# SiftWire v0.11.0

## Changed

- Ship the scheduled automation launcher inside the binary. `siftwire automation` starts it, so the launcher cannot drift from the release it drives. See the [automation guide](../automation.md).
- Embed a neutral selector prompt with the selection contract and general evidence rules. Hosts keep their own priorities in a private prompt and set `SIFTWIRE_RENDER_PROMPT`.
- Add `scripts/deploy-prooflane.sh` and `scripts/eval-sports-selection.sh`. The evaluation takes a prompt path.
- Add optional publication of each finished brief to a Notes vault with `siftwire notes publish`. It is off until `SIFTWIRE_NOTES_*` variables are set. Email stays the delivery path, and a Notes failure cannot block, delay, or change it.

## Upgrade

Install the v0.11.0 runner and same-tag skill. Runner protocol v5, configuration, the database schema, Mailgate transport, and immutable prepared-delivery replay remain unchanged. A host that still starts a separately installed launcher must install this binary before it changes `ExecStart`, because the new `ExecStart` cannot start older binaries. Follow [the migration steps](../automation.md#move-an-older-host-onto-the-embedded-launcher).

## Verification

Run `mise exec -- ./scripts/ci.sh` and `mise exec -- ./scripts/validate-release-docs.sh v0.11.0`. These gates cover the launcher through a built binary, Notes publication against a fixture that enforces the Notes API rules, and release installation. They do not establish live delivery, real Pi selection, or a live Notes publish.
