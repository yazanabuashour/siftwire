# SiftWire v0.12.0

## Changed

- Remove Prooflane. Collection and confirmation call SiftWire directly, and the launcher no longer runs Prooflane, recovers its receipts, or exports to Axiom. `scripts/deploy-prooflane.sh` and the `PROOFLANE_*` variables are gone.
- Run selection with Pi's own default model and thinking. The launcher no longer calls `model-role` or passes `--model` or `--thinking`, and run records no longer include `configured_model`.
- Stop loading the telemetry extension by absolute path. Native Pi events still validate settlement.
- Shorten the embedded selector prompt, the production skill, and the evaluator instruction without changing the selection and output contracts.

## Upgrade

Install the v0.12.0 runner and same-tag skill. Runner protocol v5, configuration, the database schema, Mailgate transport, and immutable prepared-delivery replay remain unchanged. Saved jobs and outboxes with retired fields recover directly. After installing, remove `PROOFLANE_AXIOM_DATASET` and `PROOFLANE_AXIOM_TOKEN_FILE` from the host unit; the runner ignores them.

## Verification

Run `mise exec -- ./scripts/ci.sh` and `mise exec -- ./scripts/validate-release-docs.sh v0.12.0`. These gates cover the launcher through a built binary and release installation. They do not establish live delivery or real Pi selection.
