# SiftWire v0.13.0

## Changed

- Replace Pi JSON event-stream parsing with an agent-written selection file validated by SiftWire after a successful child exit. The launcher passes one plain-text prompt with absolute instruction, input, and output paths.
- Run `pi -p --approve "<prompt>"` with stock defaults. Remove event mode, named sessions, session directories, file inlining, and launcher-specific environment overrides.
- Keep every raw selection attempt and human stdout/stderr logs. Invalid selections still retry up to three times; a nonzero child exit blocks delivery immediately.

## Upgrade

Install the v0.13.0 runner and same-tag skill following [the automation upgrade procedure](../automation.md#upgrade). Runner protocol v5, the database schema, durable job and outbox formats, Mailgate delivery, and Notes publication are unchanged. No state reset or systemd entry point change is needed. New selection receipts use `agent` rather than `pi` for the selection origin.

## Verification

Run `mise exec -- ./scripts/ci.sh` and `mise exec -- ./scripts/validate-release-docs.sh v0.13.0`. These gates cover selection files, invalid-selection retries, child exit before authorization, recovery, and release installation through a built binary. They do not establish real agent judgment or live delivery.
