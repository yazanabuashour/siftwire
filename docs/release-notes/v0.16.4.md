# SiftWire v0.16.4

## Changed

- Upgrade general URL handling to `url` 2.5.9. Keep the existing feed link parser so a literal caret and an encoded caret remain distinct feed entries. No migration rewrites saved markers, archived URLs, or deliveries.

## Rollback

Keep the current database when rolling back to v0.16.3. It reads markers for items collected on v0.16.4 in the same format as before and reuses recorded deliveries. Restoring a pre-upgrade database would discard that newer state. As with upgrades, stop automation and reconcile any pending delivery before swapping the runner and its matching skill.

## Verification

The RSS fixture checks that an already-seen literal caret link does not return and that a distinct new link does not get skipped.
