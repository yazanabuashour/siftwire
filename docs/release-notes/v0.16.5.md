# SiftWire v0.16.5

## Changed

- Use Jiff and its bundled IANA time-zone rules. For example, `2026-11-21T19:30:00Z` now renders as 12:30 p.m. MST instead of 11:30 a.m. PST in `America/Vancouver`, reflecting British Columbia's move to permanent UTC−07:00.
- Reject leap seconds when interpreting timestamps. Keep the timestamp formats used by SQLite, briefs, and notes. No database migration is needed.
- Remove `chrono-tz`. The remaining RustSec maintenance advisory for `chrono` applies only to the dependency pulled in by `feed-rs`.

## Verification

Both implementations reserialized all 120,372 timestamp values on the pre-release SQLite snapshot with no differences. A prepare-only replay produced identical output for all 146 archived delivery plans.
