# SiftWire v0.6.1

## Changed

- Keep every console tab in one stable application frame while preserving Folio's narrower reading column and existing email presentation.
- Keep dialog titles and actions visible while fields scroll. Support outside dismissal and Escape, restore focus after closing, and prevent dismissal during pending source writes. Remove duplicate Cancel buttons from edit dialogs.
- Show source options directly in grouped fields. Clarify that source preference defaults to zero, lower values win duplicate-source selection and ordinary item ordering, and the value is not an importance score. Preserve the full signed 64-bit range without changing stored priorities.
- Edit publisher rules and Active controls directly in each row. Keep names, aliases, and optional notes in the editor. All changes remain local until Save publishers; closing an editor preserves earlier inline draft changes.
- Reveal validation errors inside the scrolling dialog, including repeated attempts with the same invalid value. Restore Activity metadata spacing and improve narrow-screen controls.
- Revalidate console HTML entry pages after upgrades so browsers load the current asset references.

This patch changes the optional console and its documentation. The runner process contract, SQLite schema, source state, saved delivery plans, and email content remain unchanged. No configuration migration or priority reset is required.

The release source archive includes the console and web app. From the extracted source, run `mise install`, `mise exec -- bun install --frozen-lockfile`, and `mise exec -- ./scripts/install-console.sh`. Restart the console service, then refresh open tabs. The root installer updates the runner, not the optional console. See `docs/console.md`.
