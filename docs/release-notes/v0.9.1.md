# SiftWire v0.9.1

## Changed

- Replace evaluator-specific Codex/Pi orchestration with the vendor-neutral `siftwire-agent-eval/v1` executable JSON contract. The evaluator owns scenarios, fixtures, exact-answer checks, normalized hygiene and independent database verification; adapters own credentials, model selection, native events and session continuity.
- Provide a Pi SDK adapter using personal authentication and exact model configuration, plus an independent deterministic configuration-inspection adapter. Neither adds an agent dependency to the installed production runner.
- Record Pi actions at native tool execution hooks instead of treating tool-start events as proof of execution. Truncated and invalid calls that never execute produce no receipts; actual executions that fail still count. Preserve safe lifecycle diagnostics and private artifacts.
- Preserve symlink traversal when selecting adapter executables and support symlinked wrapper invocation. Keep the production runner protocol, skill, database schema, source selection, immutable delivery and optional console behavior unchanged.

## Upgrade

Existing v0.9.0 databases and configuration remain compatible. Install the v0.9.1 runner and register the same-tag skill; no database reset, state import or console rebuild is needed for this patch. Upgrades from v0.8.0 or earlier still require the [v5 compatibility reset](../runner-v5-reset.md).

Developer evaluation now requires an explicit `--adapter` executable. Pi model configuration belongs to the adapter, not evaluator flags. See the [adapter contract](../evals/agent-adapter.md).
