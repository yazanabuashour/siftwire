# Vendored TypeScript lint policy

This directory is the consumer snapshot of the private
`@yazanabuashour/oxlint-config` package. `SOURCE.json` records the exact source
commit. The compiled policy in `dist/` is generated and verified by that source
repository. Build and verify changes there, then replace this snapshot and update
`SOURCE.json` together.

Follow the active repository-level gate instructions. Run checkpoint review only
when those instructions require it or the user approves it.
